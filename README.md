# Fiends & Foes for Swords & Wizardry

A Foundry Virtual Tabletop content module providing a compendium of **Fiends & Foes** creatures for the unofficial [Swords & Wizardry game system](https://foundryvtt.com/packages/swords-wizardry).

## Requirements

- Foundry Virtual Tabletop v12 or later
- The `swords-wizardry` game system

The module has currently been verified on Foundry VTT v12. Compatibility with later Foundry generations should be updated only after testing.

## Installation

Once the module is listed in Foundry's package repository, install it from **Add-on Modules** in Foundry Setup.

For manual installation, use the manifest URL from the latest GitHub release:

`https://github.com/GFFClarke668/FiendsFoes/releases/latest/download/module.json`

After installation, enable **Fiends & Foes** in a Swords & Wizardry world. The included creatures are available from the **Fiends & Foes Actors** compendium.
